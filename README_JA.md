## 自己紹介

- NetEase、ByteDance、Ethereum Community Fund でエンジニアとして、大規模ユーザー向けのプロダクト開発に携わってきました。
- `Lark`、`CapCut`、`軽颜` などのプロジェクトに参加し、要件整理から設計、実装まで一通り対応できます。
